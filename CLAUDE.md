## Обзор

**KINONYX** — desktop-приложение для фильмов и сериалов: каталог и метаданные с Kinopoisk,
поиск раздач через TorAPI, воспроизведение торрента «на лету» через TorrServer → mpv
(4K, HEVC/AV1/Dolby Vision, все аудиодорожки и субтитры). Навигация — мышь и пульт/геймпад
(spatial navigation), как в PortoTV.

Родственный проект — **PortoTV** (`C:\Users\User\Desktop\test`, IPTV-плеер того же автора).
Отсюда перенесены проверенные там решения: spatial navigation, паттерн фокус-кольца,
`MpvAdapter`/`StateStore`, Rust-команды для внешних запросов. Это **отдельный проект**, не
workspace-пакет PortoTV: код скопирован и адаптирован, а не подключён, — два независимых
продукта не обязаны обновляться синхронно.

## Стек

| Слой | Технология | Почему |
|---|---|---|
| UI | React 19 + TypeScript, Vite | Тот же стек, что в PortoTV |
| Оболочка | Tauri 2 (Rust) | Легче Electron; Rust-команды для сети |
| Видео | libmpv через `tauri-plugin-libmpv` | Все кодеки, 4K, HDR, дорожки/субтитры нативно |
| Торрент → HTTP | TorrServer (Go), sidecar-процесс | Превращает magnet в локальный HTTP-поток, который mpv просто открывает |
| Метаданные | Kinopoisk Unofficial API | Постеры, описания, рейтинги, кадры, актёры, трейлеры |
| Поиск раздач | TorAPI (github.com/Lifailon/TorAPI), деплой пользователя на Vercel | RuTracker/Kinozal/RuTor/NoNameClub одним запросом |
| Состояние | zustand | Как в PortoTV |

## Архитектура

```
kinonyx/
  apps/desktop/
    src/                 React UI
      data/api.ts        типизированные обёртки над Rust-командами + нормализация ответов
      data/mock.ts       заглушки команд для браузерного превью (без Tauri)
      screens/           Home, Movie, Gallery, Search, Player, Settings
      components/        TopBar, Sidebar, HeroCarousel, RowScroll, ReleasePickerModal, ...
    src-tauri/src/
      config.rs          ключ Kinopoisk / адрес TorAPI / порт TorrServer из .env
      kinopoisk.rs       Kinopoisk API (ключ добавляется здесь, в JS не попадает)
      torapi.rs          поиск раздач
      torrserve.rs       запуск/остановка sidecar + add/get/stream
  packages/
    player-core/         PlayerAdapter, StateStore, MpvAdapter, Html5Adapter
    ui/                  Focusable, FocusGroup, клавиши, мост геймпада, иконки
```

**Все внешние запросы идут через Rust-команды**, а не `fetch` из webview: ключ Kinopoisk
не попадает в JS-бандл, и нет проблем с CORS (сторонние API не обязаны его разрешать).
Ответы Kinopoisk/TorAPI передаются как `serde_json::Value` и сужаются до нужных полей на
стороне TS (`data/api.ts`) — API большие, UI читает из каждого ответа несколько полей.

**Поток «Смотреть»:** карточка фильма → `torapi_search_title(название, год)` → окно выбора
раздачи (сортировка по сидам) → hash прямо из выдачи (у RuTor он есть; иначе
`torapi_search_id` за magnet) → `ts_add_magnet` → опрос `ts_get_torrent`, пока TorrServer
не получит метаданные от пиров (`file_stats`) → самый большой видеофайл → `ts_stream_url`
→ `PlaySource.url` в `MpvAdapter`.

**Браузерное превью** (`pnpm dev`) работает без Tauri: `data/api.ts` при `!isTauri` отвечает
из `data/mock.ts`, форматы моков повторяют реальные ответы. Воспроизведение там не работает
(нет TorrServer и mpv) — только UI.

### Проверенные форматы ответов (2026-09-22, живыми запросами)

- TorAPI `/api/search/title/all` — **объект по трекерам**, а не массив:
  `{"RuTor":[...], "RuTracker":{"Result":"Server is not available"}, ...}`. Имя трекера для
  `/api/search/id/<provider>` берётся из ключа. У RuTor в выдаче есть `Hash`. С Vercel сейчас
  отвечает только RuTor, RuTracker/Kinozal — «Server is not available».
- TorAPI `/api/search/id/<provider>` — **массив из одного элемента** `[{Name, Magnet, Hash,
  Torrent, ...}]`. У NoNameClub в поисковой выдаче нет `Hash` — только через этот запрос.
- Постеры Kinopoisk (`/images/posters/kp/…`) — 301 → 302 (кэш 10 мин) → avatars.mds.yandex.net;
  кадры (`images`) сразу с avatars, оригинал `/orig` ~660 КБ, есть `/1920x` (~280 КБ),
  `/1280x` и `/960x` — 404.
- Корень `https://ohnofreefilms.vercel.app/` отдаёт 404 — **это нормально**, у TorAPI нет
  страницы на `/`; `/api/...` работает.
- Kinopoisk `v2.1/films/search-by-keyword` — `filmId` (не `kinopoiskId`), `rating` строкой
  (`"7.9"`, бывает `"88%"`, `"null"`), `year` строкой. Нормализуется в `kpSearch`.
- Kinopoisk `v2.2/films/collections` — `kinopoiskId`, `ratingKinopoisk`, `description`,
  `posterUrl`/`posterUrlPreview`; `coverUrl` обычно `null`.

## Настройка окружения (один раз после клонирования)

1. `pnpm install` из корня.
2. `apps/desktop/src-tauri/.env` по образцу `.env.example` — `KINOPOISK_API_KEY`,
   `TORAPI_BASE_URL`, `TORRSERVE_PORT`. Файл в `.gitignore`. Он должен лежать именно в
   `src-tauri/`: `dotenvy` ищет `.env` от рабочей папки процесса вверх.
3. DLL mpv в `apps/desktop/src-tauri/lib/` (`libmpv-2.dll`, `libmpv-wrapper.dll`) —
   `npx tauri-plugin-libmpv-api setup-lib` или скопировать из PortoTV. В `.gitignore`.
4. TorrServer в `apps/desktop/src-tauri/binaries/torrserve-x86_64-pc-windows-msvc.exe`
   (релиз `TorrServer-windows-amd64.exe` с github.com/YouROK/TorrServer, переименованный
   под имя с target triple — так Tauri ищет sidecar). **Без него не собирается даже
   `cargo check`**: `tauri-build` проверяет наличие `externalBin`. В `.gitignore`.
5. Локальный переводчик: `apps/desktop/src-tauri/translator/whisper-server.exe` собирается
   из `third_party/whisper.cpp` (v1.9.4, CUDA 13, sm_75/86/120 — см. журнал 2026-09-27) и
   копируется туда; `ggml-silero-v6.2.0.bin` (VAD) лежит там же. Оба уходят в установщик
   как ресурс `translator/**/*`. Движок (llama.cpp CUDA + CUDA runtime) и модели качаются
   в приложении в `%USERPROFILE%\.kinonyx\translator`.

1. **Главная** — шапка (часы/дата, KINONYX, меню, поиск, полноэкранный режим, настройки),
   hero-карусель (размытый постер фоном + чёткий постер справа, рейтинг/жанры/название/
   описание, точки, автопрокрутка, стрелки влево/вправо листают при фокусе), ряд
   «Топ-10 популярных фильмов месяца» с номерами мест и ещё 5 подборок с описаниями.
2. **Боковое меню** — главная/фильмы/сериалы/мультфильмы/категории/каналы/настройки;
   фильмы, сериалы, мультфильмы, категории, каналы — «скоро» (эскизов пока нет).
3. **Карточка фильма** — постер, рейтинг, жанры, год, описание, «Смотреть» / «Трейлер» /
   «Онлайн», ряды «Материалы» (кадры) и «Актёры».
4. **Материалы к фильму** — просмотр кадров, влево/вправо листают; кнопка / Enter / клик —
   на весь экран (`Lightbox`).
4a. **Фильмы / Сериалы / Мультфильмы** (`CatalogScreen`, эскиз пользователя) — заголовок по
   центру, поиск справа (и меню слева), тематические полки по 6 постеров; источники полок —
   `data/catalogs.ts` (подборки Kinopoisk + фильтр `/api/v2.2/films` по жанру/типу/году).
4b. **Каналы** — раздел IPTV, перенесённый из PortoTV «как есть»: плейлисты (ссылка / файл),
   категории, каналы с «что сейчас идёт», плеер с программой и архивом (`screens/tv/*`,
   `store/tv.ts`, `packages/epg`, `src-tauri/src/epg.rs`, стили `styles/tv.css`).
5. **Поиск** — поле сразу в режиме ввода, результаты сеткой.
6. **Плеер** — перенесён из PortoTV (без EPG/архива): перемотка, дорожки, субтитры, громкость.
7. **Настройки** — статус ключа Kinopoisk, адрес TorAPI (меняется на время сессии).
