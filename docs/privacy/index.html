Политика конфиденциальности

Как приложение KINONYX для Windows и сайт проекта обращаются с данными.

Подключение YouTube

Раздел YouTube обращается к сервисам YouTube. В тестовой сборке можно подключить Google-аккаунт по коду. Подтверждение проходит на сайте Google. После подтверждения приложение получает токены доступа и обновления. Разрешение на чтение данных YouTube используется для загрузки персональной ленты. Приложение получает список видео и сведения, необходимые для отображения карточек. Политика конфиденциальности Google.

Для поиска, открытия каналов и воспроизведения приложение отправляет в YouTube поисковые запросы и идентификаторы видео или каналов. Изображения карточек загружаются с серверов YouTube.

Хранение и использование сессии

Токены хранятся в профиле KINONYX на этом компьютере и защищены средствами Windows. Приложение использует их, пока аккаунт подключён, и обращается к Google для продления сессии. Если пользователь выбирает импорт cookies.txt, приложение считывает данные сессии YouTube из выбранного файла, сохраняет нужные данные в защищённом профиле приложения и использует их для запросов к YouTube.

При отключении аккаунта приложение удаляет локальную сессию. Чтобы также отозвать разрешение, выданное при входе по коду, удалите доступ KINONYX в настройках Google-аккаунта. Исходный файл cookies.txt остаётся там, где вы его сохранили.

Настройки и сторонние службы

Настройки приложения, избранное и позиции просмотра сохраняются локально. При запросах к выбранному поставщику каталога приложение передаёт ему данные, необходимые для поиска и загрузки карточек. При включённом Discord Rich Presence приложение передаёт Discord статус просмотра, который может содержать название видео. GitHub обслуживает загрузки и проверку обновлений.

Сайт и поддержка

Сайт проекта состоит из статических страниц. GitHub Pages может регистрировать IP-адрес посетителя для безопасности. Сведения GitHub Pages о сборе данных.

С вопросами о данных обращайтесь через трекер проекта. Обращения там видны другим пользователям. Описывайте проблему без токенов, файлов сессии и личных данных.
