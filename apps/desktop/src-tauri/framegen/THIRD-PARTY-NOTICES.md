# Frame generation runtime

The portable runtime contains the following unmodified third-party programs. See the linked source releases for their license terms.

- [Python 3.14.10](https://github.com/python/cpython/tree/v3.14.10), Python Software Foundation License.
- [VapourSynth R82](https://github.com/vapoursynth/vapoursynth/tree/R82), LGPL-2.1 or later for the core.
- [NVIDIA DLSS / NGX](https://github.com/NVIDIA/DLSS/blob/main/LICENSE.txt), NVIDIA RTX SDKs License. The local development build uses a signed NVIDIA runtime supplied when assembling the package.
